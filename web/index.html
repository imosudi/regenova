Photovoltaic Generation

IEC 61724-1 Standardised Photovoltaic Modelling

Models DC-to-AC conversion efficiency, thermal clipping derating, and pyranometer plane-of-array (POA) irradiance response.

  • Thermal Clipping: Derates power output above 50.0 °C heatsink temperature.
  • Arrhenius Ageing: Tracks thermal activation energy ($E_a = 0.45\text{ eV}$) across IGBT modules.
  • Soiling Baseline Adaptation: Rolling 14-day exponential smoothing with automatic cleaning advisory.
// IEC 61724-1 Physical Power Model
P_expected = P_rated × (G_poa / 1000) × [1 + γ × (T_cell - 25)]
// Arrhenius Reaction Derating
k(T) = A × exp(-E_a / (k_B × T_kelvin))
// Verified Test Residual Threshold: ±5.0%
Aerodynamic Energy

IEC 61400-12-1 Power Curve Normalisation

Normalises site-specific barometric air density against standard atmosphere ($\rho_0 = 1.225\text{ kg/m}^3$) with gearbox bearing thermal tracking.

  • Density Correction: Continuous normalisation using barometric pressure and nacelle ambient temperature.
  • Gearbox Vibration Monitoring: Detects bearing misalignment and lubrication breakdown.
  • Yaw Misalignment Tracking: Identifies cosine aerodynamic capture losses.
// IEC 61400-12-1 Air Density Normalisation
v_norm = v_measured × (ρ_site / 1.225)^(1/3)
// Barometric Density Formulation
ρ_site = P_barometric / (R_specific × T_kelvin)
// Pitch Angle & Cut-Out Safety Envelope: 25.0 m/s
Electrochemical Storage

Utility BESS Enclosure & Cycle Degradation

Models charge/discharge setpoints, state-of-charge boundaries (5% ≤ SoC ≤ 95%), and active thermal throttling.

  • Round-Trip Efficiency: Tracks coulombic efficiency losses across lithium iron phosphate racks.
  • BMS Thermal Throttling: Initiates operational derating if cell temperatures exceed 40.0 °C.
  • Peak Shaving Integration: Automatic discharge orchestration during high PPA revenue events.
// Electrochemical Boundaries
5.0% ≤ SoC(t) ≤ 95.0% (Cell Protection Window)
// State of Charge Integration
SoC(t) = SoC(0) + ∫ [ η_c × I(t) / C_rated ] dt
// C-Rate Maximum: 1.0C Charge / 1.5C Discharge
